# Choose a license that matches the goal

Unfired currently uses **MIT** for original code, guides, fixtures, and artwork. This version does not silently change that license. Existing third-party material retains its own terms; a link to a project is not permission to relicense it.

| Goal | License family to investigate | Tradeoff |
| --- | --- | --- |
| Make reuse and integration easy | [MIT](https://opensource.org/license/mit) | Allows commercial and closed downstream reuse with required notices |
| Share changes to covered files when distributed | [MPL 2.0](https://www.mozilla.org/en-US/MPL/2.0/FAQ/) | File-level copyleft; understand combination and distribution requirements |
| Require corresponding source for covered distributed software | [GNU GPLv3](https://www.gnu.org/licenses/gpl.en.html) | Copyleft obligations need a dependency and distribution review |
| Address modified software used over a network | [GNU AGPL rationale](https://www.gnu.org/licenses/why-affero-gpl.html) | Adds source-offer obligations for covered modified network use; read exact terms |

These are orientation notes, not a full compatibility analysis or legal advice. Read the actual license and obtain advice for uncertain combinations. GNU's [license FAQ](https://www.gnu.org/licenses/gpl-faq.en.html) explains the network-use distinction; Mozilla's FAQ explains MPL's file-level design.

## What “open source everything” means here

The materials this project owns are published with a license. It does not mean private data should be public, that third-party assets become MIT, or that every downstream modification is forced open. If mandatory downstream sharing becomes a project objective, propose a deliberate license policy with contributor rights and compatibility review.

Do not add “no companies,” “no commercial use,” or retaliation clauses and still describe the result as the existing MIT license. Keep the license standard and its tradeoffs explicit.

## Before importing a dependency or example

Record source, version, license, notices, modifications, and compatibility with the intended release. Include required attribution and source-offer mechanisms where applicable. Check data, models, fonts, icons, screenshots, and examples separately from program code. AI-generated output still needs review; a model's assertion about a license is not evidence.

For a scaffold generated by this repository, MIT is copied as a starting license for original work. Do not use it to overwrite another contributor's or project's rights.
