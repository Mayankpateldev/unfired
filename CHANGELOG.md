# Changelog

## 0.2.0 — 2026-10-27

- Reoriented Unfired around an open rebuild movement, with worker recovery as a dedicated track.
- Added a method, six tracks, a 12-week curriculum, tool references, AI workflow, licensing, compatibility, migration, and release guidance.
- Added three synthetic runnable labs: API compatibility, board-format migration, and ticket-routing reconstruction.
- Added a ten-file draft project scaffolder and strict JSON result comparator with explicit exit codes.
- Added observation, contract, compatibility, migration, release, and case-study templates; governance and support routes.
- Expanded the project catalog to 24 entries: four initial implementations and 20 proposals. Added three fuller proposal briefs.
- Added behavioral coverage for HTTP contracts, golden fixtures, round trips, ambiguous inputs, rule precedence, comparison diagnostics, and file protection.

Scope limits: labs are original teaching systems, not commercial-product clones. No hardware implementation, vendor-wide compatibility, production readiness, independent audit, user-validation study, or adoption outcome is claimed. Original MIT terms are unchanged.

## 0.1.0 — 2026-10-27

- Added a layoff recovery kit, four-week learning paths, and a 90-day plan.
- Added private-workspace initialization, runway scenarios, CSV cleaning, and aggregate job-search reports.
- Added synthetic fixtures, tests, CI, project proposals, and contribution templates.

Known limits: CLI only; no hosted service, integrations, historical job-search analytics, or individualized benefit calculations. Catalog entries are proposals except for the initial CSV cleaner. Local and GitHub Actions checks cover the tools and local document targets; external URLs and factual accuracy are not automated checks.
