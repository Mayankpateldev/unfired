# Rebuild release gate

- [ ] One user and workflow are defined; a willing tester can describe the benefit.
- [ ] Permission, public sources, dates, dependencies, and provenance are recorded.
- [ ] The behavior contract includes successful cases, errors, ordering, and relevant precision/encoding rules.
- [ ] Golden fixtures are synthetic or authorized, with independently reviewed expected results.
- [ ] Meaningful compatibility tests pass; unsupported behavior is documented.
- [ ] A fresh user can reproduce setup, the core task, export, and rollback.
- [ ] Input data is preserved; destination overwrite requires deliberate handling.
- [ ] Privacy, local storage, optional network traffic, and recurring costs are explained.
- [ ] License and required dependency notices are included.
- [ ] Branding is original; no affiliation or untested equivalence is implied.
- [ ] Maintainer, support limits, known issues, and version are stated.
- [ ] No confidential source, private prompts, customer records, credentials, or unauthorized captures are included.

A checklist documents review work; it does not confer legal permission or certify production suitability.
