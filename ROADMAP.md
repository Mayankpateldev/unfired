# Roadmap

## v0.2: a usable rebuild foundation

- [x] Reposition the project around independent open alternatives; keep recovery as a separate route.
- [x] Publish a method, six tracks, tool references, and a 12-week deliverable-based curriculum.
- [x] Ship a local API teaching lab with two implementations, HTTP tests, and 18 golden cases.
- [x] Ship a strict task-export converter with expected output and round-trip checks.
- [x] Ship a deterministic routing workflow with rule-precedence and fallback tests.
- [x] Add a ten-file project-dossier generator and reusable strict JSON comparator.
- [x] Add observation, contract, compatibility, migration, release, and case-study templates.
- [x] Expand the categorized catalog to 24 entries and add three fuller proposal briefs.
- [x] Document governance, support routes, licensing tradeoffs, and existing alternatives.
- [x] Record the original scope gaps and remaining limits in the completeness audit.

## Next: evidence from people and real authorized use

- [ ] Ask willing testers to run the labs on Windows, macOS, and Linux; record reproducible friction.
- [ ] Have a contributor implement one contract without reading the supplied reference code and document the source separation.
- [ ] Validate one proposed workflow with users before adding another tool.
- [ ] Complete one authorized real-world migration or adapter with documented versions, fixtures, and rollback.
- [ ] Review a translated learning/recovery guide with two fluent speakers.
- [ ] Obtain an independent provenance/license review for a real rebuild before making broad compatibility claims.
- [ ] Establish maintenance capacity and a private project contact before promising service levels.

## Later, if evidence and maintainers justify it

- [ ] A public showcase of verified case studies, each clearly scoped and versioned.
- [ ] A low-voltage public-interface hardware exercise with appropriate specialist review.
- [ ] Optional AI features with an evaluated baseline, explicit data flow, and costs.
- [ ] Sustainable service/cooperative examples and transparent funding if funding exists.

The original v0.1 recovery guides and local utilities remain available. Proposed catalog items, hosted services, hardware implementations, customer adoption, and job-placement outcomes are not claimed as delivered. Dates follow contributor capacity and evidence, not promises of rapid platform replacement.
